# Uniswap CCA Configurator

Configure Continuous Clearing Auction (CCA) smart contract parameters for fair and transparent token distribution.

## Source

This skill is maintained in the [uniswap-ai](https://github.com/uniswap/uniswap-ai) monorepo by Uniswap Labs. The canonical source is at [`packages/plugins/uniswap-cca/skills/configurator/`](https://github.com/uniswap/uniswap-ai/tree/main/packages/plugins/uniswap-cca/skills/configurator).

## What It Does

- Guides AI agents through configuring CCA auction parameters via an interactive bulk form flow
- Covers supply schedules, pricing curves, and auction timing configuration
- Generates encoded supply schedule data for on-chain deployment
- Validates parameter constraints and provides configuration previews

## Related Skills

- **uniswap-cca-deployer**: Deploy configured CCA contracts on-chain
