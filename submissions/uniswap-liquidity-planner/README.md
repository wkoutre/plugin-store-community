# Uniswap Liquidity Planner

Plan and generate deep links for creating liquidity positions on Uniswap v2, v3, and v4.

## Source

This skill is maintained in the [uniswap-ai](https://github.com/uniswap/uniswap-ai) monorepo by Uniswap Labs. The canonical source is at [`packages/plugins/uniswap-driver/skills/liquidity-planner/`](https://github.com/uniswap/uniswap-ai/tree/main/packages/plugins/uniswap-driver/skills/liquidity-planner).

## What It Does

- Plans concentrated liquidity positions with price range selection
- Generates deep links to create positions in the Uniswap web interface
- Supports Uniswap v2, v3, and v4 pool types
- Guides users through pool selection, fee tier choices, and range strategies
